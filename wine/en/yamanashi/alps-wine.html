Overview

アルプスワイン

山梨の小さなワイナリー。'Small Winery、High quality'の合言葉を掲げ、家族経営で丁寧なワイン造りを行っています。創業60周年を機に誕生したプロダクトブランド「FOX VILLAGE」では、ぶどう本来の成分をそぎ落とさず、クリアでクリーンに造り、熟成でのレベルアップが期待できるワインを目指しています。

Features

アルプスワイン Features

1
Features 1
1962年（昭和37年）創業の家族経営ワイナリー。'Small Winery、High quality'を合言葉に掲げる。
2
Features 2
搾汁時にドライアイスを用いた果汁酸化防止を実施。Stelvinスクリューキャップへの移行で酸化防止と鮮度保持を実現。
3
Features 3
亜硫酸塩添加の最小化により保存性を向上。直営サロンには地下セラーを備え、FOX VILLAGEブランドで展開。
